# 常见问题与自愈特征库（FAQ）

| 特征 | 判定 | 建议处置 |
| :--- | :--- | :--- |
| `图形指令未处理` | 转译层不支持的图形指令 | 清理着色器缓存并切换低画质预设 |
| `引擎动态库未找到` | 工作目录错位 | 重新以游戏根目录拉起 |
| `访问违例` | 转译层内存模型问题 | 提高 `BOX64_DYNAREC_STRONGMEM` 强度后重试 |
| `执行引擎异常` | 托管层与运行时不匹配 | 停用全部插件后复现，定位问题插件 |
| `哈希不匹配` | 游戏或补丁版本漂移 | 拒绝启动并核对期望与实际哈希 |
| `内存分配失败` | 地址空间或显存压力 | 停用高开销插件并降低画质 |
| `引导配置未生效` | 注入三件套缺失或位置错误 | 核对 `winhttp.dll`、`doorstop_config.ini`、`BepInEx/` |
| `引擎日志未生成` | 引导层未成功拉起引擎 | 回查引导程序与工作目录 |
